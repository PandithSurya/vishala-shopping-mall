# Vishala Shopping Mall

A luxury Indian retail & heritage web experience for Vishala Shopping Mall.

## Features
- **Capsule Morph Header / Navbar**: Smooth ivory capsule transitions with brand lockup.
- **Hero Centerpiece**: Animated dual video showcase with audio controls and gold branding.
- **About Heritage Scroll**: Bilingual (English & Telugu) word-by-word synchronized scroll animation with royal elephant motifs.
- **Categories Staggered Gallery**: Smooth scroll-interpolated cards for Ladies, Gents, and Kids Wear with peacock zari patterns.
- **Showcase Strip**: High-fashion horizontal editorial marquee strip.
- **Branches Section**: Luxury branch cards for Siricilla, Vemulawada, and Siddipet.
- **Customer Reviews Fandeck**: Interactive card stack fandeck with touch/mouse swipe and drag mechanics.
- **Editorial Heritage Footer**: Refined Indian retail typography, branch directory, and concierge links.

## Tech Stack
- **Framework**: React + Vite
- **Styling**: Vanilla CSS (Fluid Typography, Custom Tokens, Micro-Interactions)
- **Icons**: Custom SVG icons and brand assets

## Getting Started
```bash
npm install
npm run dev
```

## Build
